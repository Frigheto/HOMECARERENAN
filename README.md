# Site - Home Care

Site especializado em direito ao Home Care (internação domiciliar) coberto por planos de saúde.

## URLs
- **Domínio de produção**: `homecare.com` (configure conforme necessário)
- **Pasta**: `/site-homecare`

## Estrutura
```
📁 site-homecare/
├── index.html
├── assets/
│   ├── logo/
│   ├── fotos/
│   └── icones/
└── *.mp4 (vídeos background)
```

## Deploy
1. Envie o conteúdo desta pasta para seu servidor/hosting
2. Configure o domínio para apontar para esta pasta
3. HTTPS é obrigatório
